# Employee Management System

A console-based Employee Management System developed using Core Java and Maven.

## Features

- Add a new employee
- View all employees
- Search employee by ID
- Update employee details
- Delete an employee
- Search employees by department
- Find the highest-paid employee
- View top-paid employees

## Technologies Used

- Java
- Maven
- IntelliJ IDEA
- Git and GitHub

## Project Structure

- `Main.java` – Main application entry point
- `MainPractice.java` – Learning and code reference
- `Test.java` – Exception-handling practice
- `model` – Employee-related model classes
- `repository` – Employee data storage and operations
- `service` – Business logic and validation
- `enums` – Employee operation result statuses

## Core Java Concepts Practiced

- Classes and Objects
- Constructors
- Encapsulation
- Getters and Setters
- ArrayList and List
- Iterators
- Comparator and sorting
- Enums
- Exception Handling
- Scanner and user input validation
- Separation of business logic and data access

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Make sure JDK is configured.
4. Load the Maven dependencies.
5. Run `Main.java`.

## Project Status

Core Java console application. JDBC and database integration will be added in a future version.
